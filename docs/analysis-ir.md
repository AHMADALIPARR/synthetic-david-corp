# AnalysisIR v1 in v0.2

`COBOL-INSPECT` performs a bounded, read-only lexical inventory inside the existing licensed Rust runtime. It requires a genuine paid `corporate.validation` entitlement and the explicit principal agent `COBOL-ANALYZER` with `legacy:cobol:read`. Neither model output nor source code can grant that permission. The empty default policy and unconfigured production signing root are preserved.

Payload fields are exactly `source`, `text`, and `dialect`. `source` has the existing `id`, `location`, and lowercase `sha256` fields. SHA-256 covers every raw UTF-8 byte of `text`, including CRLF versus LF and ignored fixed-layout areas. This differs from `DOCUMENT-INSPECT`, which hashes a canonical JSON string. Input admission remains at 8192 bytes of canonical payload JSON, source text is limited to 7000 UTF-16 units, and secret filtering runs before audit persistence. There is no file fetch, command execution, or compiler invocation.

The layouts `COBOL85-FIXED` and `COBOL85-FREE` must be explicit. These are inspector layout conventions, not proof that free source format is part of ISO COBOL-85 or is accepted by IBM COBOL II. The supplied source must contain one identifiable program and an identification division. A successful result does not mean that the source compiles.

The output identifies `schema: synthetic-david/AnalysisIR`, `version: 1`, language, declared layout, exact source reference and raw hash, and inventories of program, division, section, paragraph and data-declaration candidates. Names are uppercased. Spans identify the declaration header (level and name for data items), with one-based physical lines and ASCII columns and an exclusive end. Division headers with `USING` retain a span through the `DIVISION` word only. The surrounding runtime provenance records the responsible agent/tool, transformations, assumptions and input/output hashes; its output hash covers the complete IR.

Fixed layout uses columns 1–6 for digits/spaces, column 7 for an indicator and columns 8–72 for source. Full comment lines with `*` or `/` in column 7 are excluded. Nonblank columns 73 onward produce a diagnostic and are excluded from the inventory, while remaining part of the raw source hash. Debug and continuation indicators fail explicitly. Free layout accepts source from column 1. Inline `*>` comments and single/double quoted literals, including doubled quote escaping, are excluded from declaration matching.

Known unsupported input fails with a named error: tabs/non-ASCII bytes, bare CR line endings, fixed debug/continuation lines, multiline literals, `COPY`, `REPLACE`, `EXEC`, compiler directives and multiple program IDs. Paragraph candidates must occupy a physical line by themselves. Statement keywords and `END-*` words are excluded, so custom labels starting `END-` are also omitted. The inventories are candidate structures, not an exhaustive or compiler-validated symbol table. No PIC/data layout, statement/control-flow, external dependency, include expansion or execution semantics are established. Results expressly set `compilerValidated` and `semanticEquivalenceProven` to false; legacy remains source of truth.

The labeled fixture and opt-in principal live in `examples/cobol-inspect.json` and `examples/cobol-principal.json`. After genuine entitlement provisioning, run `david run examples/cobol-inspect.json examples/cobol-principal.json`. Build/tests need no production entitlement; cryptographic tests use explicitly labeled development signing seeds and claims that convey no production authority. CI additionally verifies that the native CLI and REXX wrapper deny protected execution with the empty trust root, leave no execution audit on license denial, and report v0.2.

The native COBOL `SD-BROKER` ABI remains unimplemented. This inspector does not call the COBOL control program or authorize banking, ledger posting, migration approval, or arbitrary shell/network access. Compiler and ABI interoperability are separate remaining work.
